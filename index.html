A little about me.

How a marine engineering background turned into an interest in software.

I finished my studies in Marine Engineering in 2023. After graduation, while waiting for sea deployment, I started learning Linux purely as a hobby. What began as curiosity about operating systems eventually grew into a deeper interest in computers, software, and how things work underneath the surface.

In 2025–2026, I got interested in building Android applications and started learning how to code using Kotlin and Java. Instead of learning only through theory, I started building projects based on problems I understand from the maritime industry.

AI has also become part of my learning process. I use it as a tool to help me understand programming concepts, explore solutions, debug problems, and build faster — while continuing to learn how the code actually works.
